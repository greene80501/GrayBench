# Task 117: decomposing the supplied two-qubit unitary

The pinned normal and hard prompts ask for a `QuantumCircuit` decomposing the
supplied 4×4 unitary using `TwoQubitBasisDecomposer` with `CXGate` as the basis.
Both original tests generate one random unitary, but check only that the return
is a nonempty two-qubit circuit containing at least one operation named `cx`.
Neither test compares `Operator(qc)` with the supplied unitary. The test also
does not reject measurement, which makes the circuit nonunitary.

The [exact-test probe](task117_oracle_probe.py) ran the pinned checks against
authored fixtures in the immutable Python 3.12.14 / Qiskit 2.4.2 evaluator
image. The normal check was called explicitly; the hard test calls it in its
own source. For **each** suite, the canonical reference passed, as did:

- A fixed two-qubit circuit with only CX, ignoring the supplied random unitary.
- A fixed CX circuit with a measurement and a classical bit.

An X-only circuit without CX and a three-qubit circuit failed in each suite.
These controls confirm that the checks actually ran. The random input was
generated by the unmodified upstream test on each invocation; the adverse
functions ignore it, so the false acceptance does not depend on its value.
Separate pinned-runtime controls show that the fixed CX is not equivalent to
the valid 4×4 identity input, the measured circuit has no unitary `Operator`,
and the canonical decomposer correctly represents identity with **zero** CX
gates. Thus a repaired oracle must not insist on CX for every valid input.

The [byte-preserved result](GrayBench-task117-exact-oracle-probe.json) has SHA-256
`1580362be6b009d3ef612c99c05f59ea9594e5df7afe7ce486f3380377c8bc7c`.
It records the pinned task and dataset digests, evaluator image, runtime,
probe-source hash, completion hashes and all ten outcomes. It is a trusted
authored exact-test diagnostic, not a protected candidate/judge run or a model
score.

A separately versioned stronger contract should require a valid two-qubit
unitary input, reject nonunitary returns, and compare the returned circuit's
operator with the supplied operator under a declared numerical/global-phase
tolerance. Vary the input and include an independent correct decomposition so
the checker does not reward only the canonical implementation. Any requirement
that the *implementation method* must call `TwoQubitBasisDecomposer` needs
separate treatment because black-box circuit equivalence cannot prove a
particular internal call. Historical upstream tests remain unchanged, and task
117 is not admitted for a verified score.
