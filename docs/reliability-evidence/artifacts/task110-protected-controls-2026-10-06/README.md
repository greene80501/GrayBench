# Task 110 protected graph development controls

The [append-only control log](results.jsonl) records 18 authored trials of the [source-bound revision](../../task110_protected_graph.py) under the immutable Python 3.12/Qiskit 2.4.2 image `sha256:2fc74bd3dd29a28154c566e21610072e24cda279c3d03f3ab8cd27f33c9b27bd`. All 18 matched their predeclared outcomes: three valid alternatives passed and six wrong answers failed in each of normal and hard. The positive alternatives were circuit copies, global-phase changes, and canceling X gates. The negative controls were empty, short, wrong-width, wrong-action, non-Clifford, and non-circuit results. The graph bridge kept the candidate in a separate container from the trusted test.

The revised public contract asks for exactly `n` native `QuantumCircuit` results with the input's qubit count and Clifford action up to global phase. It explicitly allows repeated equivalent circuits and makes no randomness or diversity claim. This deterministic adaptation is distinct from the historical pinned native task. Its private test uses one-, two-, three-, and five-qubit circuits and `n` values 0, 1, 2, 3, and 10. These finite cases do not prove correctness outside the sampled domain or prove that every valid Qiskit object can traverse the graph bridge.

The log binds exact pinned normal/hard source task digests, public and revised task digests, the private test payload, graph protocol and transport settings, engine source manifest, revision file SHA-256, candidate completion bytes, expected outcomes, observed worker outcomes, and an event hash chain.
