# Task 110: native defect and protected graph adaptation

Pinned normal task `da6ad9bb17b1f7437d7b709e9905b6e8e7fa82c282b76bd25466e89f3cc337d1` and hard task `7ff2acaded27c33c081fa11fd44fa7ec3b9413b77cc17e1c6eba28f2ee05dbe1` request `n` random equivalent Clifford circuits. Their test calls `n=10`, checks each returned item, and never checks the list length. The [source-bound empty-list controls](artifacts/native-literal-mutants-2026-10-06-v2/README.md) pass in both suites. The test also uses `Operator.equiv` with `rtol=atol=0.4`. In the [pinned-image fixed-seed diagnostic](artifacts/task110-tolerance-2026-10-06/README.md), that comparator accepted 98 of 100 Cliffords that both exact-tableau and strict-operator checks rejected. IBM documents [`Operator.equiv`](https://eu-de.quantum.cloud.ibm.com/docs/en/api/qiskit/2.4/qiskit.quantum_info.Operator) as equivalence up to global phase with configurable tolerances; a large absolute tolerance can erase meaningful matrix differences.

The original native track must preserve the pinned prompt and test for historical reproduction, but task 110 is ineligible for a correctness headline while these false passes remain. A protected adaptation will use a new public contract and a new private judge identity. It asks for exactly `n` `QuantumCircuit` outputs implementing the same Clifford action as an input Clifford circuit, up to global phase, for nonnegative `n` in the declared development domain. It will not claim to evaluate randomness or diversity: a single returned list cannot establish a distribution, and the original task does not specify one. Repeated copies are valid for this adapted deterministic contract and are labeled accordingly. The adapted result cannot be numerically compared as an exact replication of the original random-circuit task.

The trusted test runs in the protocol-4 graph judge process; candidate code runs in a separate container. It uses deterministic one-, two-, three-, and five-qubit Clifford inputs and several `n` values including zero and ten. For each output it checks list length, native `QuantumCircuit` type, width, and equality of Qiskit `Clifford` tableaux. A global-phase variant and a syntactically different but equivalent circuit must pass. Empty, wrong-length, wrong-width, non-Clifford, and wrong-operator controls must fail with their outcome class recorded. IBM defines the [Clifford group modulo global phase](https://eu-de.quantum.cloud.ibm.com/docs/en/api/qiskit/qiskit.quantum_info.Clifford), and local pinned-image checks confirm phase-equivalent circuits compare equal while a different Clifford does not.

The private test, public prompt, extraction policy, graph transport, Docker image, pinned source ancestry, controls, and source files must be content-bound in an append-only development log. The verifier must reproduce exact case identities, judge manifests, candidate hashes, worker outcomes, and the log chain. Controls establish only local consistency; graph transport may reject a valid Qiskit object it cannot encode, and no task-admission or publication claim is made until independent review and transport adequacy are demonstrated. The native and protected results remain separate tracks.
